# 🌐 Personal Portfolio

A personal portfolio website built to showcase my coding skills, learning journey, and projects.

🔗 **Live site:** [maramaouini.netlify.app](https://maramaouini.netlify.app)

---

## 🛠️ Tech Stack

- **React** — UI framework
- **React Router** — client-side routing
- **React Bootstrap** — component library
- **Tailwind CSS** — utility-first styling
- **Netlify** — deployment

---

## 📁 Project Structure

```
src/
├── assets/        # Fonts, images, project screenshots
├── components/    # Reusable UI components
├── context/       # React context
└── data/          # Static data (projects, skills, etc.)
```
